Email Marketing Basics

Membuat, mengirim, dan mengelola mailing list untuk newsletter efektif.

1. Konfigurasi Server

Secara default, Odoo membatasi jumlah email harian untuk mencegah spam. Untuk pengiriman massal:

  • Anda bisa mengaktifkan Dedicated Server di menu Configuration > Settings.
  • Ini memungkinkan penggunaan server pengiriman khusus (SMTP) untuk reputasi email yang lebih baik.

2. Membuat Mailing Baru

Di dashboard Email Marketing, klik New:

  • Recipients: Pilih "Mailing List" untuk mengirim ke daftar subscriber. Anda bisa memilih Multiple Mailing Lists sekaligus di kolom ini.
  • Subject: Judul email yang menarik.
  • Design: Gunakan drag-and-drop editor Odoo untuk mendesain body email.

3. Pengiriman (Sending)

Setelah selesai mendesain:

  • Klik Send untuk mengirim segera atau Schedule untuk nanti.
  • Setelah klik Send, status mailing akan berubah dari Draft menjadi In Queue (Dalam Antrean) sebelum akhirnya terkirim (Sent).

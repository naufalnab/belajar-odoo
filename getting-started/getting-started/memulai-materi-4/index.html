Materi 4

Filter, Grup, & Tampilan

Belajar cara mengelola data dengan filter canggih dan mengubah tampilan sesuai kebutuhan kita.

📸 Screenshot: Input nama project & tombol Create

1. Menggunakan Filter & Pencarian

Odoo memungkinkan kita menyaring ribuan data hanya dalam hitungan detik.

  1. Buka aplikasi Sales. Perhatikan bar pencarian di kanan atas.
  2. Secara default, filter My Quotations aktif. Klik tkita X untuk menghapusnya dan melihat semua data.
  3. Klik ikon dropdown (tkita panah bawah) di search bar untuk membuka menu filter.
  4. Coba pilih filter stkitar (seperti Quotations atau Sales Orders).
📸 Screenshot: Menu dropdown Filter di aplikasi Sales

2. Menambahkan Salesperson Baru

Agar fitur pengelompokan (Group By) lebih terlihat efeknya, mari kita buat satu user tambahan sebagai Salesperson.

  1. Buka menu utama (Home), masuk ke Settings.
  2. Klik menu Users & Companies > Users di bagian atas.
  3. Klik tombol New.
  4. Isi Nama: misal Budi Sales (Login bebas, misal: budi@test.com).
  5. PENTING: Di tab Access Rights, cari bagian Sales dan pilih User: All Documents.
  6. Klik ikon awan (Save) untuk menyimpan.
Jika hak akses Sales tidak diisi, user ini tidak akan muncul sebagai opsi Salesperson.
📸 Screenshot: Form User baru dengan sorotan pada Access Rights > Sales

3. Mengelompokkan Data (Group By)

Sekarang, mari kita kelompokkan data penjualan berdasarkan Salesperson yang baru kita buat.

  1. Kembali ke aplikasi Sales.
  2. Buka menu dropdown pencarian, pilih tab Group By.
  3. Pilih Salesperson.
  4. Data sekarang terpisah menjadi beberapa kelompok (Admin, Budi Sales, dll).
📸 Screenshot: Data Sales yang dikelompokkan (header biru per nama user)

4. Menyimpan Filter Favorit

Jangan habiskan waktu mencari filter yang sama setiap hari. Simpan saja!

  1. Setelah mengatur filter/grup yang kita suka, klik tab Favorites di menu dropdown.
  2. Klik Save current search. Beri nama, misalnya Laporan Tim.
  3. Centang Use by default jika ingin filter ini aktif otomatis.
  4. Klik Save.
📸 Screenshot: Menu Favorites > Save current search

5. Mengenal Jenis-Jenis Tampilan (Views)

Odoo memiliki berbagai cara untuk menampilkan data. Navigasi ini ada di pojok kanan atas.

A. List View (Daftar)

Tampilan tabel stkitar. Cocok untuk melihat detail banyak data sekaligus.

📸 Screenshot: Tampilan List View (Tabel)

B. Kanban View (Kartu)

Tampilan visual kartu. Coba Drag & Drop kartu pesanan dari kolom Admin ke kolom Budi Sales (pastikan Group By Salesperson aktif).

📸 Screenshot: Tampilan Kanban (Kartu-kartu)

C. Calendar View

Melihat jadwal dokumen berdasarkan tanggal.

📸 Screenshot: Tampilan Kalender

D. Pivot View

Tabel analisis data (seperti Excel Pivot) untuk laporan ringkasan.

📸 Screenshot: Tampilan Pivot Table

E. Graph View

Visualisasi data (Bar, Line, Pie Chart).

📸 Screenshot: Tampilan Grafik

F. Activity View (Aktivitas)

Melihat jadwal tugas (To-Do, Email, Call).
🔴 Merah: Terlambat | 🟢 Hijau: Akan datang | 🟡 Kuning: Hari ini

📸 Screenshot: Tampilan Activity (Grid warna-warni)

G. Map View (Peta)

Menampilkan lokasi partner di peta.

📸 Screenshot: Tampilan Peta dengan pin lokasi

Materi 3

Sinkronisasi Google Calendar

Hubungkan jadwal Odoo Anda dengan Google Calendar agar tetap sinkron di semua perangkat.

📸 Screenshot: Input nama project & tombol Create

1. Membuat Project di Google API Console

Langkah pertama adalah membuat "wadah" di Google Cloud untuk menampung izin akses Odoo.

A. Buat Project Baru

  1. Buka Google Cloud Console.
  2. Klik dropdown nama project di bagian atas (sebelah logo Google Cloud).
  3. Pada jendela yang muncul, klik tombol New Project di pojok kanan atas.
📸 Screenshot: Jendela "Select a Project" & Tombol New Project

B. Beri Nama Project

  1. Isi kolom Project Name dengan nama: Odoo Calendar Project.
  2. Biarkan "Location" apa adanya (biasanya 'No Organization').
  3. Klik tombol Create dan tunggu beberapa detik hingga notifikasi selesai.
📸 Screenshot: Input nama project & tombol Create

C. Aktifkan Google Calendar API

  1. Pastikan project yang baru dibuat sudah terpilih di bagian atas.
  2. Klik menu navigasi (garis tiga) > APIs & Services > Library.
  3. Ketik Google Calendar API di kolom pencarian.
  4. Klik hasilnya, lalu tekan tombol biru bertuliskan Enable.
📸 Screenshot: Halaman detail API & Tombol Enable

2. Konfigurasi OAuth (Google Auth Platform)

Ikuti langkah-langkah di wizard "Google Auth Platform" secara berurutan.

A. App Information

  1. Klik tombol biru Get started di tengah layar.
    2. 📸 Screenshot: Tampilan awal (Get Started)
  2. Isi App name: Odoo Calendar.
  3. Isi User support email dengan email Anda.
  4. Klik Next.
📸 Screenshot: Pengisian Nama Aplikasi & Email

B. Audience

  1. Pilih opsi: External.
  2. Klik Next.
📸 Screenshot: Memilih opsi "External"

C. Contact Information & Finish

  1. Pada kolom Email addresses, masukkan kembali email Anda.
  2. Klik Next.
  3. Pada halaman Finish, tinjau data lalu klik tombol Create.
📸 Screenshot: Mengisi Email di Contact Information

D. Test Users & Publish (Masuk dari Sidebar)

⚠️ Wajib: Anda sekarang berada di halaman Overview. Anda harus masuk ke menu Audience untuk menyelesaikan setup.
  1. Lihat menu di sebelah kiri (Sidebar), klik menu Audience.
  2. Scroll ke bagian Test users.
  3. Klik Add Users, masukkan email Google Anda, lalu Simpan.
    4. 📸 Screenshot: Mengisi Email di Contact Information
  4. Cari tombol PUBLISH APP (biasanya di bagian "Verification Status").
  5. Konfirmasi hingga status berubah menjadi In production.
📸 Screenshot: Klik menu 'Audience' di kiri, lalu tambah Test Users

3. Membuat Client ID & Client Secret

Dapatkan "kunci" untuk dimasukkan ke Odoo.

  1. Klik menu Credentials > Create Credentials > OAuth client ID.
    2. 📸 Screenshot: Pengisian Authorized Redirect URIs
  2. Application type: Web application.
    3. 📸 Screenshot: Pengisian Authorized Redirect URIs
  3. Authorized JavaScript Origins: Masukkan URL database Odoo Anda (Contoh: https://naufal.odoo.com).
  4. Authorized redirect URIs: Masukkan URL database diikuti kode berikut:
    /google_account/authentication
  5. Klik Create.
📸 Screenshot: Pengisian Authorized Redirect URIs
Simpan Client ID dan Client Secret yang muncul. Jangan bagikan kode ini kepada siapapun!

4. Pengaturan di Sisi Odoo

Sekarang, masukkan kunci dari Google ke dalam Odoo.

  1. Buka aplikasi Calendar di Odoo.
  2. Masuk ke menu Configuration > Settings.
  3. Centang opsi Google Calendar.
  4. Masukkan Client ID dan Client Secret yang Anda dapatkan tadi.
  5. Klik Save.
📸 Screenshot: Odoo Calendar Settings (materi-3-step-4-odoo-settings.png)

5. Melakukan Sinkronisasi

Langkah terakhir adalah mengaktifkan sinkronisasi di tampilan kalender.

  • Kembali ke tampilan kalender utama Odoo.
  • Klik tombol Sync with Google yang baru muncul di sisi kanan.
  • Pilih akun Google Anda dan berikan izin akses.
📸 Screenshot: Tombol Sync with Google di Kalender
Hati-hati: Jika Anda menghapus atau mengubah jadwal di Odoo, perubahan tersebut akan langsung terkirim ke Google Calendar peserta meeting. Gunakan database tes untuk eksperimen!

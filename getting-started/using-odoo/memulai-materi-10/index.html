Import & Export Data

Cara cepat memindahkan data massal masuk dan keluar dari Odoo.

📸 Ilustrasi Utama: Alur Import & Export

1. Export Data

Anda dapat mengekspor data dari Odoo ke dalam file Excel (.xlsx) atau CSV. Ini sangat berguna untuk reporting atau ketika Anda ingin memindahkan data ke sistem lain.

Caranya:

  1. Buka List View (tampilan daftar) untuk data yang ingin diekspor (misal: Contacts).
  2. Centang kotak (checkbox) di samping nama record yang ingin dipilih.
  3. Tombol Actions (ikon gerigi) akan muncul di tengah atas. Klik tombol tersebut.
  4. Pilih menu Export.
📸 Screenshot: Tombol Actions > Export

2. Opsi "I want to update data"

Saat jendela pop-up Export muncul, Anda akan melihat checkbox bertuliskan "I want to update data" (import-compatible export).

💡 Mengapa opsi ini penting?

Jika Anda mengekspor data dengan tujuan untuk mengeditnya di Excel lalu mengimpornya kembali ke Odoo, Anda WAJIB mencentang opsi ini.

Fitur ini memastikan Odoo menyertakan kolom External ID. ID ini adalah "kunci" yang memberi tahu Odoo bahwa "Budi Santoso" yang Anda upload ulang adalah Budi Santoso yang sama dengan yang ada di sistem (untuk di-update), bukan Budi Santoso baru.

📸 Screenshot: Pop-up Export dengan opsi Update Data

3. Import Data

Untuk memasukkan data baru secara massal (seperti 1000 kontak pelanggan sekaligus), gunakan fitur Import.

Langkah Memulai Import:

  • Klik ikon Gear (Action/Favorites) di pojok kiri atas (di bawah nama menu utama).
  • Pilih Import Records.
  • Klik Upload File dan pilih file Excel/CSV Anda.
Tips: Sebelum melakukan impor final, selalu klik tombol Test untuk memastikan tidak ada error pada format data Anda.
📸 Screenshot: Menu Favorites/Gear > Import Records

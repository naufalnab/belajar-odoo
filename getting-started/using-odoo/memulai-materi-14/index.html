Custom Digest Emails (dengan Odoo Studio)

Menambahkan KPI khusus ke dalam email ringkasan Anda menggunakan Odoo Studio.

📸 Ilustrasi Utama: Odoo Studio Interface untuk Digest Email

1. Persiapan Kustomisasi

Terkadang KPI standar tidak cukup. Anda dapat menambahkan KPI sendiri namun membutuhkan modul Odoo Studio.

Syarat Field:

Untuk membuat KPI baru, Anda perlu menyiapkan dua jenis field pada model Digest:

  1. Checkbox Field: Untuk opsi enable/disable KPI tersebut.
  2. Integer/Float Field: Untuk menyimpan nilai hasil perhitungan KPI (computed field).
📸 Screenshot: Tampilan menambahkan field baru di Odoo Studio

2. Menulis Kode Kustom (Python)

Karena KPI bersifat dinamis (dihitung berdasarkan data real-time), Anda perlu memasukkan kode Python untuk menghitung nilainya.

Contoh kode untuk menghitung nilai peluang besar (Big Opportunities): 

self._calculate_company_based_kpi("crm.lead",
    "x_studio_kpi_big_opportunities_value",
    date_field="create_date",
    additional_domain=[
     ('type', '=', 'opportunity'),
     ('expected_revenue', 'greater-than-or-equal', 10000),
    ])

Lokasi untuk memasukkan kode tersebut adalah di menu:
Settings > Technical > Database Structure > Models > (Pilih Model Terkait) > (Pilih Field) > Tab "Compute"

📸 Screenshot: Area "Compute" di pengaturan teknis Field

3. Konfigurasi Penerima (Recipients)

Penting untuk menentukan siapa saja yang berhak menerima email ringkasan ini.

Anda dapat mengaturnya langsung di formulir Digest Email pada tab Recipients. Di sana Anda bisa memilih user mana saja yang akan berlangganan (Subscribe).

📸 Screenshot: Tab Recipients pada form Digest Email

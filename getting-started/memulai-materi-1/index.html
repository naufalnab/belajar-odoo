Memulai Odoo: Setup Database & Konfigurasi Awal

Panduan langkah demi langkah membuat database Odoo dari nol hingga siap digunakan.

1. Membuat Database Baru

Langkah pertama adalah inisialisasi lingkungan Odoo.

  • Buka odoo.com
  • Klik "Mulai Sekarang - Gratis"

Pilih aplikasi awal: Sales & CRM

2. Pengisian Data & Negara

⚠️ Pilih negara dengan BENAR. Ini menentukan pajak & akuntansi.
  • Isi nama & email
  • Isi nama perusahaan
  • Pilih negara

3. Mengatur Logo Perusahaan

  1. Settings → Companies
  2. Klik Update Info
  3. Upload logo
  4. Save

4. Aktivasi Database

⏳ Aktivasi maksimal 3 jam via email

5. Menambah User

  1. Settings → Users
  2. Klik New
  3. Isi nama & login

6. Instalasi Aplikasi

  • Menu → Apps
  • Cari Inventory
  • Install

7. Developer Mode & Demo Data

⚠️ Jangan gunakan demo data di production

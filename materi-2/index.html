Navigasi & Antarmuka Odoo

Menguasai dashboard, shortcut, dan navigasi dokumen dengan efisien.

1. Ikon Top Bar & Dashboard

Di pojok kanan atas dashboard Odoo, terdapat serangkaian ikon navigasi. Mari kita bedah urutannya:

🔴 Attendance (Titik Merah)

Fitur ini digunakan untuk check-in (masuk) atau check-out (pulang) kerja secara cepat.

ℹ️ Troubleshooting: Jika ikon tidak muncul, pastikan modul hr_attendance terinstall, user terhubung ke Employee, dan opsi "Attendances from Backend" aktif.
📸 Screenshot Ikon Titik Merah (materi-2-icon-attendance.png)

📞 VoIP (Telepon)

Fitur Voice over IP. Memungkinkan Anda menelepon pelanggan langsung dari database Odoo.

ℹ️ Info Teknis: Memerlukan modul VoIP (Enterprise) dan konfigurasi server SIP.
📸 Screenshot Ikon Telepon/VoIP (materi-2-icon-voip.png)

🤖 Odoo AI (Generative AI)

Fitur kecerdasan buatan untuk membantu menulis konten, memperbaiki tata bahasa, atau mengotomatisasi tugas dalam workflow Anda.

ℹ️ Info Teknis: Memerlukan API Key (biasanya dari OpenAI/ChatGPT) yang dikonfigurasi di pengaturan sistem umum.
📸 Screenshot Ikon AI/Robot (materi-2-icon-ai.png)

💬 Conversations (Chat)

Membuka modul Discuss. Di sini Anda bisa melihat chat internal tim, channel diskusi, dan notifikasi pesan.

📸 Screenshot Ikon Chat Bubble (materi-2-icon-discuss.png)

🕘 Activities (Jam)

Pusat manajemen tugas. Menampilkan To-do list, jadwal meeting, atau deadline telepon/email yang harus Anda kerjakan hari ini.

ℹ️ Kenapa kosong?
Menu ini hanya berisi data jika Anda sudah menjadwalkan aktivitas.
Cara memunculkannya: Buka dokumen apa saja (misal: Kontak atau Sales Order), cari bagian Chatter (riwayat pesan), lalu klik tombol Activities > Schedule Activity.
📸 Screenshot Ikon Jam/Activities (materi-2-icon-activities.png)

⚙️ Studio (Ikon Obeng & Tang)

Klik ini untuk masuk ke mode edit, dimana Anda bisa mengubah tampilan aplikasi atau menambah field baru secara visual.

ℹ️ Info: Hanya muncul jika modul Odoo Studio terinstall (Fitur Enterprise).
📸 Screenshot Ikon Studio (materi-2-icon-studio.png)

🏢 Multi-Company Toggle

Ikon ini memungkinkan Anda berpindah antar cabang atau entitas perusahaan yang berbeda dalam satu database tanpa harus logout.

ℹ️ Info Teknis: Ikon ini hanya muncul jika Anda mengaktifkan lebih dari satu perusahaan di Settings > Companies. Jika hanya ada satu perusahaan, ikon ini akan tersembunyi.
📸 Screenshot Ikon Gedung/Perusahaan (materi-2-icon-multicompany.png)

2. Navigasi Cepat (Command Palette)

Anda bisa berpindah antar menu, mencari dokumen, atau menjalankan perintah dengan sangat cepat tanpa menyentuh mouse.

⌨️ Shortcut: Tekan Ctrl + K (Windows) atau Command + K (Mac).

Apa saja yang bisa Anda lakukan?

  • Cari Menu/Modul: Cukup ketik nama modul (misal: "Sales", "Inventory") lalu tekan Enter.
  • Pencarian Fleksibel: Anda bisa asal ketik kata kunci. Misal ketik "Products" untuk mencari menu produk di dalam aplikasi apapun.
  • Navigasi Cepat: Gunakan simbol / diikuti nama aplikasi untuk berpindah instan (Contoh: /Sales).
  • Cari Dokumen: Ketik nomor dokumen (misal: SO001) untuk mencari record spesifik di seluruh database.
📸 Screenshot Menu Command Palette saat mengetik kata kunci (materi-2-shortcuts.png)

3. Menu Akun: Keamanan & Preferensi

Klik foto profil Anda di pojok kanan atas. Odoo akan menampilkan Account Menu (menu akun), bukan langsung ke halaman profil.

📸 Screenshot Account Menu (materi-2-account-menu.png)

Isi menu akun ini adalah:

  • Help
    Mengakses dokumentasi resmi dan bantuan Odoo.
  • Shortcuts
    Menampilkan daftar shortcut keyboard penting di Odoo.
  • Status (Online / Away / Do Not Disturb / Offline)
    Mengatur status kehadiran Anda di sistem chat internal Odoo.
  • My Preferences
    Pengaturan utama akun personal Anda, meliputi:
    • Bahasa antarmuka (Language)
    • Zona waktu (Time Zone)
    • Format tanggal & jam
    • Dark Mode
    • Keamanan akun (Password & 2FA)
  • My Databases
    Menampilkan daftar database Odoo yang terhubung dengan akun Anda (khusus Odoo Online / SaaS).
  • My Subscription
    Informasi langganan Odoo (paket, billing, dan status akun).
  • Install App
    Shortcut untuk menginstal aplikasi Odoo baru langsung dari App Store.
  • Log out
    Keluar dari akun Odoo dengan aman.
💡 Catatan Penting:
Hampir semua pengaturan penting terkait keamanan dan personalisasi akun berada di menu My Preferences, bukan di halaman terpisah.

4. Breadcrumbs & Smart Buttons

Saat Anda membuka dokumen (misal: Sales Order), perhatikan:

  1. Breadcrumbs (Kiri Atas): Jejak navigasi Anda (misal: Quotations > SO001). Klik untuk kembali ke halaman sebelumnya.
  2. Smart Buttons (Kanan Atas Dokumen): Tombol pintas ke dokumen terkait (misal: melihat Invoices atau Delivery dari Sales Order tersebut).

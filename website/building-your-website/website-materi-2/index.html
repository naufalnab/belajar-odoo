Menggunakan Building Blocks

Desain halaman web dengan cepat menggunakan sistem drag-and-drop Odoo.

📸 Ilustrasi: Building Blocks Panel

1. Apa itu Building Blocks?

Building Blocks memungkinkan Anda mendesain website dengan cepat cukup dengan drag-and-drop (seret dan lepas). Terdapat 4 jenis blok:

  • Structure: Kerangka dasar halaman.
  • Features: Fitur spesifik seperti fitur perbandingan atau bagan.
  • Dynamic Content: Konten yang berubah dinamis, misal produk terbaru.
  • Inner Content: Konten kecil di dalam blok lain.

Cara Menambahkan Blok

Klik tombol Edit di pojok kanan atas, pilih blok yang diinginkan dari panel kanan, lalu drag ke halaman Anda.

2. Kustomisasi & Layout

Setiap blok bisa dikustomisasi melalui tab Customize. Anda bisa mengubah warna background dengan memilih Color Preset yang tersedia.

Grid vs Kolom (Cols)

Odoo menyediakan dua gaya tata letak (Layout):

  • Grid: Bebas memindahkan dan mengubah ukuran elemen (gambar/teks) di mana saja. Bisa menumpuk gambar di belakang teks.
  • Cols (Columns): Mengatur jumlah elemen per baris. Sangat rapi dan terstruktur.

Untuk mode Mobile, secara default Odoo akan menampilkan 1 kolom agar mudah dibaca. Anda bisa mengubah jumlah kolom mobile dengan klik ikon 📱 di editor.

📸 Screenshot: Pilihan Layout (Grid / Cols)

3. Visibilitas (Desktop vs Mobile)

Anda bisa menyembunyikan elemen tertentu agar hanya muncul di perangkat tertentu:

  • Pilih elemen yang ingin disembunyikan.
  • Di tab Customize, cari bagian Visibility.
  • Klik ikon Mata untuk Hide on Mobile atau Hide on Desktop.
Tips: Klik ikon HP di bagian atas editor untuk melihat pratinjau (preview) tampilan mobile website Anda.

Conditional Visibility

Anda juga bisa menyembunyikan blok berdasarkan kondisi tertentu (misal: hanya untuk User Login atau Negara tertentu) melalui opsi Visible for atau Hidden for.

4. Manajemen Blok (Duplikat & Simpan)

Fitur tambahan untuk mempercepat kerja Anda:

  • Duplikat Blok: Klik ikon duplikat untuk menyalin blok beserta isinya.
  • Reorder (Urutkan): Gunakan panah naik/turun atau drag icon untuk memindah posisi blok.
  • Simpan Blok (Save): Kustomisasi blok bisa disimpan! Klik ikon 💾 (disket) di tab Customize. Blok yang disimpan akan muncul di bagian Custom.

Domain Names

Memahami, mendaftarkan, dan mengonfigurasi nama domain untuk website Odoo Anda.

📸 Infografis: Website Domain Configuration

1. Apa itu Nama Domain?

Nama domain adalah alamat berbasis teks untuk mengidentifikasi lokasi online, seperti website. Ini jauh lebih mudah diingat daripada alamat IP numerik.

Secara default, database Odoo Online dan Odoo.sh menggunakan subdomain dari odoo.com (contoh: perusahaansaya.odoo.com).

Namun, Anda bisa menggunakan custom domain name dengan:

  • Mendaftarkan nama domain gratis (khusus Odoo Online).
  • Mengonfigurasi nama domain yang sudah Anda miliki.

2. Mendaftarkan Domain Gratis dengan Odoo

Odoo menawarkan domain gratis selama satu tahun untuk database Odoo Online. Caranya:

  1. Buka Database Manager di akun Odoo Anda.
  2. Klik tombol ⚙️ (gear) di sebelah nama database, pilih Domain Names.
  3. Cari nama domain yang diinginkan dan cek ketersediaannya.
  4. Pilih domain, isi formulir Domain Owner, dan klik Register.
Penting: Verifikasi email dari noreply@domainnameverification.net wajib dilakukan agar domain tetap aktif.
📸 Langkah-langkah Registrasi Domain

3. DNS Records: A, CNAME, MX, TXT

Untuk mengelola domain, Anda perlu memahami jenis-jenis DNS record:

  • A Record: Menyimpan alamat IP domain. Dibuat otomatis.
  • CNAME (Canonical Name): Mengarahkan satu domain/subdomain ke domain lain. Penting untuk mengarahkan www.domainanda.com ke database Odoo.
  • MX (Mail Exchange): Mengarahkan email ke server mail yang benar (misal: Google Workspace).
  • TXT: Digunakan untuk verifikasi kepemilikan domain (misal: verifikasi Google).
Perubahan DNS bisa memakan waktu hingga 72 jam untuk menyebar ke seluruh dunia (propagasi).
📸 Contoh Konfigurasi DNS

4. Konfigurasi Domain yang Sudah Dimiliki

Jika Anda sudah punya domain dari provider lain (GoDaddy, Namecheap, dll), ikuti langkah ini:

  1. CNAME Record: Tambahkan record CNAME di provider DNS Anda.
    • Name: www
    • Target: databaseanda.odoo.com
  2. Redirect Naked Domain: Arahkan domainanda.com (tanpa www) ke www.domainanda.com. Odoo menyarankan menggunakan Cloudflare untuk ini jika provider Anda tidak mendukung redirect HTTPS.
  3. Mapping di Odoo: Di Database Manager > Domain Names, klik Use my own domain. Masukkan www.domainanda.com dan verifikasi.
📸 Konfigurasi Domain Sendiri

5. SSL & Web Base URL

SSL (HTTPS): Odoo otomatis membuat sertifikat SSL untuk domain yang dipetakan dengan benar. Prosesnya bisa memakan waktu hingga 24 jam.

Web Base URL: Pastikan untuk mengatur domain Anda di menu Website > Configuration > Settings. Masukkan domain Anda di kolom Domain (contoh: https://www.domainanda.com). Ini memastikan semua link portal dan email menggunakan alamat yang benar.

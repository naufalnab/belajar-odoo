Website - Building Your Website

Images & Media

Mempercantik website dengan gambar berkualitas, video, dan background dinamis.

📸 Ilustrasi: Media Manager Odoo

1. Integrasi Unsplash (Gambar Gratis)

Mencari gambar berkualitas tinggi seringkali sulit dan mahal. Odoo terintegrasi langsung dengan Unsplash, perpustakaan stok foto gratis.

  • Akses Mudah: Cari gambar berdasarkan kata kunci langsung dari editor website.
  • Kualitas Tinggi: Ribuan gambar resolusi tinggi siap pakai.
  • Hak Cipta Aman: Bebas royalti untuk penggunaan komersial.
Tips: Ketik kata kunci dalam Bahasa Inggris saat mencari di Unsplash untuk hasil terbaik.

2. Background Shapes

Untuk membuat tampilan website lebih modern dan tidak kaku ("kotak-kotak"), Odoo menyediakan fitur Background Shapes.

  • Ini adalah bentuk grafis (gelombang, miring, abstrak) yang memisahkan antar blok.
  • Fungsinya untuk menciptakan alur visual yang estetis dan dinamis.
  • Dapat disesuaikan warnanya agar selaras dengan tema website.
📸 Screenshot: Contoh Background Shapes

3. Integrasi Video

Video meningkatkan keterlibatan pengunjung (engagement). Di Odoo, cara terbaik menambahkan video adalah dengan metode Embed.

Cukup salin tautan (URL) dari YouTube atau Vimeo dan tempel (paste) ke dalam blok video di Odoo. Odoo akan otomatis menyematkannya.

Hindari Upload Langsung: Mengunggah file video besar langsung ke server Odoo dapat memperlambat website. Selalu gunakan hosting video eksternal (YouTube/Vimeo).

4. Optimasi Gambar (WebP)

Kecepatan website adalah segalanya. Odoo secara otomatis mengonversi dan menggunakan format gambar WebP.

  • Ukuran Kecil: WebP jauh lebih ringan dibanding JPEG atau PNG dengan kualitas yang setara.
  • Loading Cepat: Website terbuka lebih cepat, pengunjung lebih senang.
  • SEO Friendly: Google menyukai website yang cepat.

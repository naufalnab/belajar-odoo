Access Rights

Mengontrol siapa yang boleh membeli dan batas persetujuannya.

1. Memblokir Vendor

Bagaimana mencegah pembelian dari vendor bermasalah?

  • Anda tidak bisa benar-benar "memblokir" (prevent) karyawan pilih vendor (opsi D).
  • Tapi Anda bisa memberi peringatan (Warning/Blocking Message), namun secara teknis 'Prevent' hard-stop tidak tersedia sebagai opsi default sederhana di soal ini (Jawabannya: I cannot prevent...).
  • Note: Di Odoo versi terbaru bisa archive, tapi sesuai konteks soal ini, jawabannya adalah tidak bisa prevent total via blocking message semata.

2. User Roles

Mengatur hak akses:

  • Buka General Settings > Manage Users.
  • Pilih karyawan, lalu edit bagian Access Rights.
  • Anda bisa set sebagai User atau Administrator.

3. Approval Rules

Membatasi nominal pembelian:

  • Jika Anda set "Purchase Order Approval" minimum amount $200.
  • Maka setiap RFQ di atas $200 yang dibuat oleh Purchase User (bukan Admin) memerlukan persetujuan Manager/Admin.
  • Admin bisa bypass aturan ini.

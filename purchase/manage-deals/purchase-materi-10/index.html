Eletronic Data Interchange (EDI)

Pertukaran dokumen otomatis antar database Odoo (PO ke SO).

1. Manfaat Utama

Mengapa menggunakan EDI?

  • Memungkinkan pertukaran dokumen terstruktur antar database (structured exchange).
  • Mengurangi error input manual karena PO Anda otomatis jadi SO di sistem vendor.

2. Otomasi PO ke SO

Prosesnya:

  • Saat Anda upload file XML PO ke sistem vendor (Odoo Sales app).
  • Sales Order generated automatically dengan semua detail order.
  • Tanpa ketik ulang!

3. Lokasi File Asli

Di mana file XML asli tersimpan?

  • File tersebut akan terlihat di bagian Chatter.
  • Ini berguna untuk audit trail dan memastikan data asli sesuai.

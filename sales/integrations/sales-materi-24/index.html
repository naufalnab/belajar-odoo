Integrations: Gelato (Print on Demand)

Menghubungkan Odoo dengan layanan Print on Demand untuk otomatisasi penuh.

📸 Ilustrasi: Integrasi Odoo x Gelato

1. Sinkronisasi Produk

Bagaimana cara menarik produk dari Gelato ke Odoo?

  • Gunakan API Key dari akun Gelato Anda untuk menghubungkan kedua platform.
  • Odoo akan menarik "Product Templates" dari Gelato.
  • Semua varian (ukuran, warna, desain) akan otomatis terbuat di Odoo sebagai Product Variants.
📸 Screenshot: Gelato API Key Configuration

2. Webhooks & Order Status

Agar Odoo tahu status pesanan (sedang dicetak, dikirim, dll), kita perlu Webhooks.

  • Di dashboard Gelato > Developer > Webhooks.
  • Tambahkan URL Webhook dari Odoo Anda.
  • Pilih Event: order_status_updated.
  • Ini memastikan saat Gelato memperbarui status (misal: "Shipped"), Odoo otomatis menerima update tersebut.
📸 Screenshot: Webhook Event 'order_status_updated'

3. Menambahkan Pengiriman (Shipping)

Gelato memiliki biaya kirim sendiri. Bagaimana menagihnya ke pelanggan?

  • Pada Sales Order di Odoo yang berisi produk Gelato, klik tombol Add Shipping.
  • Odoo akan mengambil tarif real-time dari Gelato berdasarkan alamat pelanggan.
  • Biaya ini akan ditambahkan sebagai baris "Delivery" di Sales Order Odoo.
📸 Screenshot: Tombol 'Add Shipping' di Sales Order

Promotion Basics & Discounts

Cara membuat kode diskon dan program promosi dasar di Odoo Sales.

📸 Ilustrasi: Tampilan Discount & Loyalty

1. Persiapan Awal (Configuration)

Sebelum membuat diskon, pastikan fiturnya sudah aktif.

  1. Buka aplikasi Sales.
  2. Pergi ke menu Configuration > Settings.
  3. Cari bagian Pricing.
  4. Centang opsi Discounts, Loyalty & Gift Card.
  5. Klik tombol Save di kiri atas.
📸 Screenshot: Sales > Configuration > Settings > Pricing
💡 Info (Mata Uang): Jika harga masih dalam USD, ubah ke Rupiah (IDR) dengan cara:
  • Buka Invoicing / Accounting > Configuration > Currencies. Cari IDR dan aktifkan toggle-nya.
  • Buka Settings > Companies > Update Info. Ganti Currency menjadi IDR (Indonesian Rupiah).
⚠️ Perhatian (Update Harga): Setelah mengganti mata uang, harga produk mungkin terlihat sangat murah (misal Rp 750).
Silakan buka menu Products, pilih salah satu produk, dan ubah Sales Price menjadi angka yang wajar (misal Rp 150.000) agar simulasi diskon lebih realistis.

2. Membuat Program Promosi Baru

Mari kita buat program diskon pertama kita.

  1. Masih di aplikasi Sales, klik menu Products > Discount & Loyalty.
  2. Klik tombol New.
  3. Program Name: Isi dengan 15% Off Orders.
  4. Program Type: Pilih Discount Code (Kode Diskon).
📸 Screenshot: Form pembuatan Discount & Loyalty baru

3. Menetapkan Syarat Program

Siapa yang boleh pakai? Kapan berlakunya?

  • Start Date / End Date (Validity): Tentukan tanggal kadaluarsa (atau biarkan kosong selamanya).
  • Limit Usage: Centang kotak ini untuk membatasi jumlah pemakaian (misal: 420 kali).
  • Available On: Centang Sales dan Website (agar bisa dipakai di toko online juga).
Tips: Jika field Available On tidak muncul, pastikan modul Website/eCommerce juga terinstal.
📸 Screenshot: Bagian General Information (Validity, Limit)

4. Peraturan & Ganjaran (Rules & Rewards)

Inti dari promo: Apa syaratnya? Apa hadiahnya?

A. Conditional Rules (Syarat)

  1. Klik tombol Add atau baris di tabel Rules.
  2. Discount Code: Masukkan kode unik, contoh disc15.
  3. Minimum Quantity: Bisa diset minimal pembelian (misal 1 unit).
  4. Minimum Purchase: Bisa diset minimal total belanja (misal Rp 100.000,00).
  5. Klik Save & Close.

B. Rewards (Hadiah)

  1. Klik baris di tabel Rewards.
  2. Reward Type: Pilih Discount.
  3. Discount: Isi 15 %.
  4. Apply On: Pilih Order (Diskon 15% untuk total belanja).
  5. Max Discount: (Opsional) Batasi maksimal potongan harga dalam nominal uang.
  6. Klik Save & Close.
📸 Screenshot: Popup konfigurasi Reward (Discount 15% on Order)

5. Pengujian (Testing)

Ayo kita coba apakah kodenya berhasil!

  1. Buka Website (Shop).
  2. Masukkan produk apa saja ke keranjang (Cart).
  3. Lanjut ke proses Checkout/Payment.
  4. Cari kolom Discount Code / Promo Code.
  5. Ketik disc15 lalu Apply.
  6. Pastikan total harga berkurang 15% secara otomatis!
📸 Screenshot: Tampilan Cart dengan potongan harga sukses

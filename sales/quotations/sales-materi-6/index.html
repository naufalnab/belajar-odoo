PDF Quote Builder

Modifikasi Header dan Footer penawaran PDF Anda agar terlihat lebih profesional.

📸 Ilustrasi: PDF Quote Builder Odoo

1. Mengakses Halaman Headers/Footers

Odoo memungkinkan kita menyesuaikan tampilan PDF penawaran (Quotation) untuk memberikan kesan yang lebih personal dan profesional.

Ada dua cara untuk mengakses pengaturan ini:

  1. Buka menu Sales > Configuration > Settings.
  2. Cari bagian Quotations & Orders.
  3. Klik link bertuliskan "Configure your document layout" (atau document template).
  4. Alternatif: Terkadang link ini berlabel "Headers/Footers" tergantung versi Odoo.
📸 Screenshot: Sales Settings > Document Layout Link

2. Menggunakan PDF Quote Builder

Setelah masuk ke konfigurasi layout, kita bisa mengatur elemen header dan footer.

  1. Layout: Pilih template dasar (Light, Boxed, Bold, Striped).
  2. Font: Pilih jenis huruf yang sesuai dengan branding perusahaan.
  3. Logo: Pastikan logo perusahaan sudah terupload dengan resolusi tinggi.
  4. Colors: Sesuaikan warna utama dan sekunder dokumen.
  5. Background: Tambahkan latar belakang custom jika diperlukan.
📸 Screenshot: Konfigurator Layout Dokumen

3. Mencari Technical Name (Developer Mode)

Kadang kita perlu memasukkan field dinamis ke dalam header/footer (misal: Tanggal Penawaran, Nama Salesperson). Untuk itu, kita butuh "Technical Name" dari field tersebut.

Bagaimana cara mendapatkannya?

  1. Aktifkan Developer Mode (di Settings > General Settings > Scroll paling bawah > Activate the developer mode).
  2. Buka formulir Sales Order atau Quotation.
  3. Arahkan kursor (hover) ke atas label field yang ingin diketahui namanya.
  4. Sebuah kotak hitam (tooltip) akan muncul. Cari baris bertuliskan Field: (contoh: date_order atau user_id).
📸 Screenshot: Tooltip field di Developer Mode

4. Tab Quote Builder

Selain header/footer global, kita bisa memodifikasi konten PDF per penawaran.

Di dalam formulir Quotation/Sales Order, terdapat tab khusus bernama Quote Builder (di beberapa versi mungkin disebut PDF Options atau sejenisnya, tapi fungsinya sama).

  • Di sini kita bisa mengupload file PDF tambahan (misal: Brosur Produk, Syarat & Ketentuan) yang akan digabungkan dengan penawaran.
  • Kita juga bisa mengatur header/footer spesifik untuk dokumen ini saja.
📸 Screenshot: Tab Quote Builder di Sales Order

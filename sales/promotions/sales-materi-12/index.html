Loyalty Points & Coupons

Cara membuat dan mengonfigurasi program kupon di Odoo Sales.

📸 Ilustrasi: Coupons & Loyalty

1. Konfigurasi Awal

Pastikan fitur kupon sudah aktif di pengaturan.

  1. Buka menu Sales > Configuration > Settings.
  2. Cari opsi "Discounts, Loyalty & Gift Card" dan pastikan diaktifkan.
  3. Simpan pengaturan jika ada perubahan.
📸 Screenshot: Sales > Configuration > Settings

2. Membuat Program Kupon Baru

Kupon memerlukan kode unik untuk ditukarkan.

  1. Pergi ke Products > Discount & Loyalty.
  2. Klik New.
  3. Program Name: Berikan nama (contoh: 20% Discount).
  4. Program Type: Pilih Coupons.
Catatan: Kode kupon biasanya untuk pelanggan tertentu dan sekali pakai, sedangkan kode promosi untuk umum dan dapat digunakan berkali-kali.
📸 Screenshot: Form pembuatan Program Kupon

3. Menetapkan Aturan (Conditional Rules)

Syarat apa yang harus dipenuhi?

  1. Klik Add di bagian Rules.
  2. Minimum Quantity: Isi dengan 2 (pelanggan harus membeli setidaknya 2 produk).
  3. kita juga dapat menetapkan syarat lain seperti jumlah pembelian minimum, atau membatasi pada produk/kategori tertentu.
  4. Klik Save & Close.
📸 Screenshot: Konfigurasi Rules

4. Menetapkan Hadiah (Rewards)

Berapa besar diskon atau hadiahnya?

  1. Klik pada hadiah yang sudah ada untuk mengedit.
  2. Reward Type: Pilih Discount.
  3. Discount: Ubah nilai menjadi 20 %.
  4. Apply On: Pilih Order (diskon untuk keseluruhan pesanan).
  5. Klik Save & Close.
📸 Screenshot: Konfigurasi Rewards

5. Menghasilkan Kupon (Generate Coupons)

Setelah program disimpan, kita perlu membuat kode kuponnya.

  1. Klik tombol Generate Coupons di bagian kiri atas.
  2. Pilih salah satu metode:

A. Anonymous Customers

  • Tentukan jumlah kupon yang ingin dibuat.
  • Odoo akan membuat kupon tersebut untuk kita bagikan sendiri.

B. Selected Customers

  • Customers: Pilih pelanggan khusus (contoh: "Mitchell Admin").
  • Jika dibiarkan kosong, kupon akan dibuat untuk semua pelanggan dalam database.
  • Expiration Date: Dapat mengatur tanggal kedaluwarsa (opsional).
  • Klik Generate and Send Coupons. Odoo akan mengirimkan email berisi kode kupon langsung kepada pelanggan.
📸 Screenshot: Popup Generate Coupons

6. Penukaran Kupon

Bagaimana pelanggan menggunakan kuponnya?

  1. Pelanggan menerima email berisi kode.
  2. Pelanggan mengunjungi situs web e-commerce dan menambahkan produk ke keranjang (mematuhi syarat minimum 2 unit).
  3. Masukkan kode di kolom Discount code or gift card.
  4. Diskon 20% akan dipotong dari total pesanan.
Catatan: Kode kupon tidak terikat dengan akun pengguna tertentu; kode tersebut dapat diberikan kepada orang lain untuk digunakan.
📸 Screenshot: Tampilan Checkout dengan Kupon

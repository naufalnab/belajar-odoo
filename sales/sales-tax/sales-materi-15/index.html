Dasar-Dasar Pajak (Tax Basics)

Memahami cara kerja Tax Localization, perhitungan pajak, dan kustomisasi pajak tingkat lanjut.

📸 Ilustrasi: Pengaturan Pajak di Odoo

1. Tax Localization Package

Odoo berusaha membuat pengaturan pajak semudah mungkin dengan menggunakan Tax Localization Package.

  • Paket ini otomatis terinstal berdasarkan Negara (Country) yang Anda pilih saat pertama kali membuat database perusahaan.
  • Paket ini sudah berisi aturan pajak standar yang berlaku di negara tersebut (misal: PPN 11% untuk Indonesia, GST untuk Singapura, dsb).
Penting: Selalu pilih negara yang benar saat inisialisasi database agar laporan pajak (Tax Report) sesuai dengan regulasi pemerintah setempat.
📸 Screenshot: Pemilihan Negara pada Database

2. Perhitungan Pajak: Percentage of Price

Metode perhitungan pajak yang paling umum adalah Percentage of Price.

  • Cara Kerja: Pajak dihitung dengan mengalikan persentase tertentu (misal 11%) dengan harga jual produk.
  • Sederhana, standar, dan digunakan di hampir semua transaksi ritel.

Anda bisa membuat pajak baru atau mengedit yang sudah ada di menu Accounting > Configuration > Taxes.

📸 Screenshot: Konfigurasi Pajak Percentage of Price

3. Perhitungan Pajak Lanjutan: Python Code

Untuk kasus pajak yang sangat kompleks (misal: pajak progresif, pajak bersyarat), Odoo menyediakan opsi perhitungan via Python Code.

  • Syarat: Anda perlu menginstal modul teknis bernama "Define Taxes as Python Code" dari menu Apps.
  • Setelah diinstal, opsi "Python Code" akan muncul di pilihan "Tax Computation".
  • Ini memberikan fleksibilitas tanpa batas bagi developer untuk menentukan logika pajak.
📸 Screenshot: Opsi Python Code pada Tax Computation

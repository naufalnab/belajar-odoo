eCommerce - Mengatur Katalog Produk

Product Page

Mengelola halaman produk Anda: Desain, Visibilitas, dan Fitur.

1. Edit Halaman Produk (Shop)

Halaman produk di Odoo bukan sekadar daftar statis. Anda bisa mendesainnya!

  • Buka halaman produk apa saja di website (Shop).
  • Klik Edit di pojok kanan atas.
  • Sama seperti Website Builder, Anda bisa men-drag & drop Building Blocks ke halaman produk.
  • Ingin menambahkan tabel spesifikasi? Testimoni? Banner promo? Semua bisa.

2. Status Published vs Unpublished

Bagaimana jika produk belum siap dijual? Jangan dihapus!

  • Di bagian atas halaman produk (saat mode Edit atau View), ada tombol toggle status.
  • Unpublished (Merah): Produk hanya terlihat oleh Admin. Pengunjung tidak bisa melihatnya. Cocok untuk draft atau produk musiman yang sedang off.
  • Published (Hijau): Produk live dan bisa dibeli pelanggan.
Penting: Mengarsipkan (Archive) produk di backend akan menghilangkannya dari website sepenuhnya, sedangkan Unpublished membiarkannya ada tapi tersembunyi.

3. Fitur Tambahan Halaman Produk

Melalui menu Customize saat mengedit halaman produk, Anda bisa mengaktifkan:

  • Wishlist: Agar pelanggan bisa menyimpan produk favorit.
  • Comparison: Membandingkan spesifikasi beberapa produk.
  • Add to Cart Sticky: Tombol beli yang tetap terlihat saat discroll.

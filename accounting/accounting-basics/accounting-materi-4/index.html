Import Data & Opening Balances

Cara mengimpor data akuntansi dan saldo awal ke Odoo.

Importing Data

Odoo memungkinkan Anda mengimpor data (Contacts, Products, Invoices, Journal Entries) menggunakan file Excel (.xlsx) atau CSV.

Tips Import:

  • Templates: Gunakan template import yang disediakan Odoo untuk memastikan format kolom benar.
  • One Sheet: Untuk impor faktur (invoices/bills), disarankan menggabungkan semua line dalam satu sheet, lalu mengimpornya melalui Import Wizard di Accounting Settings.

Clearing Account

Saat mengimpor saldo awal (Opening Balance), disarankan menggunakan akun sementara atau Suspense Account / Clearing Account.

  • Ini menghindari duplikasi saldo di akun Receivable/Payable saat mengimpor baik General Ledger maupun Open Invoices.
  • Ini memberikan entri untuk merekonsiliasi transaksi bank pembuka.

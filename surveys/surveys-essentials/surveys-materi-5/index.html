Live Session Surveys

Mengubah survei menjadi presentasi interaktif dan menarik.

1. Apa itu Live Session?

Live Session memungkinkan host mengontrol alur survei secara real-time. Peserta menjawab pertanyaan secara bersamaan sesuai yang ditampilkan host.

  • Cocok untuk presentasi, kelas, atau webinar.
  • Menampilkan leaderboard dan grafik hasil secara instan.

2. Memulai Sesi (Session Manager)

Klik tombol Create Live Session:

  • QR Code: Ditampilkan di layar besar agar peserta mudah bergabung via HP.
  • URL Pendek: Alternatif untuk akses via browser.
  • Jika ada peserta terlambat bergabung (Late Join), mereka akan langsung masuk ke pertanyaan yang sedang aktif (current step), bukan dari awal.

3. Batasan Mode Live

Beberapa fitur survei reguler tidak tersedia di Live Session karena sifatnya yang linier dan dipandu host:

  • Pagination settings (One page per question): Otomatis diatur oleh host.
  • Peserta tidak bisa kembali ke pertanyaan sebelumnya (No Back Button).

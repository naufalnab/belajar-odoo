Project Basics (Kanban)

Mengelola task menggunakan Kanban View, Stages, dan Status.

1. Manfaat Kanban View

Fitur powerfull untuk manajemen visual:

  • Memberikan gambaran jelas (overview) semua task aktif.
  • Memungkinkan edit cepat tanpa membuka record satu per satu.
  • Drag and drop untuk mengubah stage (tahapan).
  • All of the above: Semua poin di atas benar.

2. Stage vs Status

Penting untuk dibedakan:

  • Kanban Stage: Kolom di Kanban (To Do, In Progress, Done) -> Melacak progres workflow.
  • Task Status: State spesifik (Ready, Blocked, Changes Requested, Done) -> Menandai kondisi task.
  • Mereka adalah fitur yang BERBEDA (Stage != Status).
  • Apakah bisa membuat custom Kanban stages? Ya, tentu saja.

3. Status "Changes Requested"

Apa yang terjadi jika status diatur ke "Changes Requested"?

  • Task TIDAK otomatis pindah stage.
  • Tapi follower akan dinotifikasi.
  • Dan titik status kuning akan muncul pada kartu task untuk menandakan butuh perhatian.
  • All of the above.

4. Menutup Task

Cara yang benar menutup task (selain drag ke stage Done):

  • Mengubah status task menjadi "Done" (Hijau) atau "Canceled".
  • Drag ke tong sampah (trash)? Tidak disarankan, itu menghapus data.

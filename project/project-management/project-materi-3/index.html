Project - Project Management

Project Settings & Kanban

Memahami pengaturan dasar proyek dan elemen visual Kanban.

1. Membuat Project Baru

Saat membuat project baru di Odoo:

  • Nama Project: Wajib diisi.
  • Customer: Opsional. Project bisa bersifat internal dan tidak terkait customer.
  • Nama Project bisa diubah kapan saja melalui Settings Project atau langsung dari Kanban/List view jika diizinkan, tetapi biasanya melalui Settings Form.

2. Elemen Kartu Proyek (Kanban)

Apa saja yang muncul di setiap kartu project pada view utama?

  • Tag: Label untuk kategorisasi.
  • Project Manager: Foto/Avatar penanggung jawab.
  • Scheduled Date (jika ada).
  • Yang TIDAK muncul: Due Dates (biasanya di level task, bukan project) dan Project Description (hidden).

3. Membedakan Project

Agar mudah dikenali, Anda bisa menambahkan:

  • Tags: Untuk filter dan grouping.
  • Warna (Colors): Memberikan kode warna pada kartu.
  • Favorites: Menandai bintang untuk prioritas.
  • Anda BISA menggabungkan semuanya (Tags + Colors + Star).

Project - Project Management

Managing Projects

Mengelola tahapan proyek (Project Stages) dan pelaporan status (Project Updates).

1. Mengaktifkan Project Stages

Secara default, Project Stages mungkin sudah terlihat di Kanban view dashboard Project. Namun, Anda dapat mengelolanya melalui:

  • Configuration > Settings: Pastikan opsi "Project Stages" diaktifkan jika tersedia.
  • Configuration > Project Stages: Untuk membuat atau mengedit tahapan proyek (Stages) secara global.
  • Ingat: Anda tidak perlu masuk ke settings setiap project; stage seringkali diatur di level global atau per project type.

2. Kanban Stages vs Project Status

Penting untuk membedakan antara posisi di Kanban (Stage) dan Status kesehatan proyek:

  • Memindahkan Project ke Stage Lain (misal dari "New" ke "In Progress") TIDAK secara otomatis mengubah "Status" kesehatannya.
  • Status (On Track, At Risk, Off Track) dikelola secara terpisah, biasanya melalui fitur Project Updates.
  • Jadi, pernyataan "Moving a project to a different Kanban stage affects its status" adalah False.

3. Indikator Warna di Kanban

Di bagian atas setiap kolom Stage di Kanban View, terdapat bar berwarna (hijau, kuning, merah, abu-abu). Apa artinya?

  • Ini menunjukkan jumlah project dengan masing-masing status dalam stage tersebut.
  • Contoh: Bagian hijau menunjukkan jumlah project yang "On Track", merah untuk "Off Track" atau "At Risk", dll.
  • Ini memberikan visualisasi cepat tentang kesehatan proyek di setiap tahapan.

4. Project Updates

Fitur "Project Updates" memungkinkan manajer memberikan laporan berkala. Saat Anda membuat Update baru (klik "New" di dashboard Project Update):

  • Anda memilih status (On Track, At Risk, dll).
  • Status Proyek akan diperbarui mengikuti status yang Anda pilih di update TERAKHIR ini.
  • Tujuannya agar stakeholder selalu melihat status terkini berdasarkan laporan terbaru.

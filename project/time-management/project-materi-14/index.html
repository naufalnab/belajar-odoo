Project - Time Management

Advanced Timesheets

Fitur lanjutan Timesheets: Reminder, Billing Rates, dan Leaderboard.

1. Timesheet Reminders

Odoo dapat mengirimkan pengingat email otomatis:

  • Untuk Karyawan: Mengingatkan agar mengisi timesheet jika belum lengkap.
  • Untuk Manager (Approver): Mengingatkan untuk memvalidasi timesheet tim mereka.

2. Billing Rate Indicators

Indikator ini (biasanya di view By Employee) membantu melihat efisiensi:

  • Anda harus mengaktifkannya di Timesheets > Configuration > Settings.
  • Menampilkan persentase jam yang dapat ditagih (billable) vs non-billable.

3. Leaderboard

Gamifikasi timesheet dengan Leaderboard:

  • Menampilkan ranking karyawan berdasarkan total jam kerja.
  • Syarat: Encoding method (satuan pencatatan waktu) di sistem harus diset ke Days / Half-Days (bukan Hours) agar fitur ini muncul/relevan di beberapa versi Odoo Enterprise.

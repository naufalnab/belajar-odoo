Timesheets Basics

Mencatat waktu kerja (Timesheets) dan validasi.

1. Cara Mencatat Waktu

Ada beberapa cara mencatat timesheet di Odoo:

  • Start/Stop Timer: Di task view, tekan Start untuk mulai, Stop untuk berhenti. Jika kurang dari 1 menit tapi sudah lebih dari beberapa detik, biasanya dibulatkan ke unit terkecil yang diset (misal 15 menit) atau dicatat sesuai durasi jika durasi timer cukup signifikan (di Odoo 16, timer pendek < 1 menit mungkin diabaikan atau 0).
  • Manual Encoding: Masukkan durasi langsung di tab Timesheets pada task.
  • Keyboard Shortcut: Gunakan huruf di sebelah kiri baris timesheet (misal 'a', 'b') untuk start/stop timer (fitur Awesome Timesheet/Grid view tertentu). Jika menggunakan Grid View (Enterprise), tekan huruf shortcut.

2. Indikator Waktu

Di Timesheet Grid View:

  • Warna Merah pada total jam di bawah kolom hari: Menandakan total jam kerja kurang dari jam kerja kontraktual (misal < 8 jam).
  • Warna Hijau: Jam kerja tercapai atau lebih.

3. Validasi Timesheet

Manager memvalidasi timesheets:

  • Biasanya dilakukan di Grid View atau List View.
  • Pilih entri timesheet (checkbox) lalu klik tombol Validate.
  • Di Odoo modern, validasi sering dilakukan per periode atau per karyawan di aplikasi Timesheets > To Validate.

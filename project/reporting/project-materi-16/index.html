Project - Reporting

Project Dashboard

Analisis data proyek secara real-time dan snapshot.

1. Mengakses Dashboard

Project Dashboard dapat diakses dari:

  • Menu Reporting > Dashboard di aplikasi Project.
  • Link smart button dari dalam Project form (jika ada, tergantung versi).
  • Tapi biasanya bukan dari Top Bar project (Top Bar lebih ke operasional task/burndown).

2. Data yang Ditampilkan

Dashboard menampilkan angka agregat:

  • Tasks: Jumlah task (open, closed, overdue).
  • Timesheets: Total jam kerja vs rencana.
  • Documents, SO Items, Vendor Bills: Terkait profitabilitas dan billing.
  • Burndown Chart: Visualisasi sisa pekerjaan.

3. Project Updates (Snapshots)

Cara terbaik menyimpan status saat ini untuk referensi nanti:

  • Buat New Project Update.
  • Saat membuat update (status report), Odoo secara otomatis mengambil "Snapshot" dari dashboard data pada titik waktu tersebut.
  • Ini berguna untuk laporan mingguan/bulanan ke stakeholder.

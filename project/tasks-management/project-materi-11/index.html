Project - Tasks Management

Automations

Membuat tindakan otomatis saat task berpindah stage.

1. Mengakses Automations

Bagaimana cara mengatur otomatisasi pada Kanban stage?

  • Buka Kanban view project.
  • Klik ikon Gear (Settings) di sebelah nama stage (kolom).
  • Pilih "Automations" (atau "Edit Stage" lalu tab Automations).
  • Catatan: Opsi tombol "Automations" di pojok kanan atas view biasanya untuk Automation Rules global (Studio/Developer), tapi konteks di sini adalah Stage-based automation.

2. Triggers & Actions

Komponen utama otomatisasi:

  • Trigger: Pemicu aksi (misal: "Task moved to stage").
  • Action: Apa yang dilakukan (misal: "Create Activity", "Send Email/SMS", "Assign to...").

3. Contoh: Automated Call Activity

Jika Anda mengatur "Schedule Activity: Call" saat task masuk stage tertentu:

  • Sistem tidak menelpon secara harfiah.
  • Sistem akan membuat Activity (Todo) tipe "Call" di Chatter task tersebut.
  • User yang ditugaskan akan melihat notifikasi untuk menelpon seseorang.

Project Milestones

Menandai pencapaian penting dalam project dan menagih (invoice) berdasarkan milestone.

1. Apa itu Milestone?

Milestone adalah penanda progres signifikan dalam project.

  • Milestones bersifat project-specific (terikat pada project, bukan task individu).
  • Anda bisa menghubungkan Tasks ke Milestone (via field Milestone di task form), tapi Milestone sendiri levelnya ada di Project.

2. Status Milestone

Kapan Milestone dianggap tercapai (Reached)?

  • Secara otomatis: Ketika semua tasks yang terhubung ke milestone tersebut selesai (Done/Canceled).
  • Status milestone akan berubah menjadi hijau di dashboard project update.
  • Anda juga bisa menandainya secara manual.

3. Invoicing based on Milestones

Untuk menagih klien berdasarkan pencapaian:

  • Buat Service Product dengan Invoicing Policy: Based on Milestones.
  • Buat Sales Order dengan produk tersebut -> Confirm -> Project dibuat.
  • Ketika milestone di project tercapai (Reached), Anda bisa kembali ke Sales Order dan membuat Invoice.

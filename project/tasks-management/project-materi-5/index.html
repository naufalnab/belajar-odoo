Project - Tasks Management

Task Creation

Berbagai cara membuat task: Email Alias dan Website Form.

1. Email Alias untuk Tasks

Odoo memungkinkan pembuatan task via email:

  • Anda bisa memiliki Satu Email Alias per Project (misal: `project-A@mycompany.com` untuk Project A, `support@mycompany.com` untuk Project B).
  • Email yang dikirim ke alias ini akan otomatis menjadi Task baru di project tersebut.
  • Judul email menjadi Judul Task, isi email menjadi Deskripsi.

2. Otomatisasi Email Template

Mengonfigurasi Email Template pada sebuah Kanban Stage:

  • Digunakan untuk memberi notifikasi otomatis ke pelanggan saat status task berubah.
  • Email dikirim saat task DIPINDAHKAN KE stage tersebut.
  • Contoh: Saat task dipindah ke "Done", kirim email "Tugas Anda sudah selesai".

3. Task dari Website Form

Jika menggunakan formulir di Website Odoo:

  • Task akan dibuat di Project yang telah dipilih saat konfigurasi form di website editor.
  • Tidak otomatis masuk ke "Website Project" atau "Dispatch", melainkan spesifik ke project tujuan (misal: "Customer Support").

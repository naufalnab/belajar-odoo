Task Dependencies

Mengatur urutan pengerjaan task yang saling berkaitan (Blocked By).

1. Apa itu Task Dependencies?

Fitur ini memungkinkan Anda mengatur prioritas antar Tasks (bukan project). Tujuannya agar task dikerjakan sesuai urutan yang benar (Sequential).

  • Untuk mengaktifkan: Go to Project > Configuration > Settings, enable "Task Dependencies".

2. Cara Mengatur Dependency

Ada beberapa cara mengatur ketergantungan:

  • Dari Task Form: Tab "Blocked By" -> Add a line.
  • Dari Gantt View: Drag & drop connector (panah) dari satu task ke task lain.
  • Di Kanban View, task yang terblokir akan ditandai dengan ikon jam pasir merah (atau warna merah pada status bar).

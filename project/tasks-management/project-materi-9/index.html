Recurring Tasks

Mengotomatiskan pembuatan tugas yang berulang secara berkala.

1. Mengaktifkan Fitur Recurrence

Fitur ini tidak aktif secara otomatis. Anda harus:

  • Pergi ke Project > Configuration > Settings.
  • Cari bagian "Tasks Management" dan aktifkan checklist Recurring Tasks.
  • Klik Save.

2. Membuat Tugas Berulang

Setelah diaktifkan, field baru "Recurrent" akan muncul di form Task:

  • Buka task yang ingin diulang.
  • Centang kotak Recurrent (atau klik smart button "Recurrence").
  • Atur frekuensi pengulangan (Harian, Mingguan, Bulanan, Tahunan) dan kapan pengulangan berakhir (Forever, End Date, atau Number of Repetitions).

3. Menghentikan Pengulangan

Jika Anda tidak ingin task tersebut berulang lagi:

  • Buka task terakhir atau task induknya.
  • Klik pada status Recurrence (biasanya berupa link atau smart button hijau).
  • Pilih opsi untuk menghentikan recurrence atau hapus checklist "Recurrent".

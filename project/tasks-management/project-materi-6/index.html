Project - Tasks Management

Sales Integration

Menjual layanan (Service) yang otomatis membuat Project dan Task.

1. Project dari Sales Order

Project yang terhubung dengan Sales Orders biasanya bersifat:

  • Billable (Dapat ditagihkan). Waktu yang dihabiskan atau milestone yang dicapai akan ditagih ke klien.
  • Sering digunakan oleh perusahaan jasa (konsultan, developer, dll).

2. Kapan Task Dibuat?

Task atau Project otomatis dibuat saat Sales Order:

  • Confirmed (Dikonfirmasi).
  • Bukan saat Draft (masih penawaran) dan bukan menunggu Invoice.
  • Momen "Confirm" adalah pemicu (trigger) pembentukan project.

3. Konfigurasi Service Product

Agar penjualan produk Service otomatis membuat Project dengan banyak Task:

  • Pada form Product (tab Sales), set "Create on Order" menjadi Project & Task.
  • PENTING: Anda harus menghubungkannya dengan Project Template yang sudah memiliki tasks di dalamnya.
  • Jika hanya memilih "Project & Task" tanpa template, Odoo hanya akan membuat project kosong dengan satu task default dari item SO tersebut.

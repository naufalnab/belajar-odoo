Gmail Plugin

Ubah email menjadi leads langsung dari inbox Gmail Anda.

1. Instalasi Add-in

Cara menambahkan Odoo ke Gmail:

  • Klik tanda (+) di sidebar kanan Gmail (Get Add-ons).
  • Cari "Odoo".
  • Pilih 'Odoo Inbox Addin' dan klik Install.

2. Membuat Lead/Opportunity

Setelah terinstal:

  • Buka email dari prospek.
  • Buka sidebar Odoo.
  • Di bawah bagian 'Opportunities', klik tombol Create.
  • Odoo akan otomatis mengambil subjek email dan kontak pengirim.

3. Membuat Task dari Email

Anda juga bisa membuat Project Task:

  • Jika Anda membuat Task dan Project sekaligus dari plugin:
  • Task tersebut akan masuk ke stage 'New' di dalam database project Anda.
